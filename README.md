# Moon Phase New Tab

This is a Chrome extension that changes your new tab page.  
It shows a calm and nice dashboard with the moon as the main focus.


## What it does:

- Shows today's real moon phase with a beautiful moon
- Displays the date, weekday, and a live clock (12h or 24h)
- Gives you sunrise, sunset, golden hour, and twilight times
- Shows moonrise, moonset, moon age, and how lit the moon is
- Changes the background daily with a space image that fades in smoothly
- Gives you a new space quote every day
- Has a search bar that works with Google, DuckDuckGo, or Bing
- Lets you customize things like location, time format, search engine, quotes, background rotation, and temperature unit with a reset button
- Saves your preferences across devices
- Works on any screen, supports keyboard navigation, and respects motion settings

## How to install it (unpacked version):

1. Download or copy this folder to your computer.
2. Open Chrome, Edge, Brave, Arc, or any Chromium browser.
3. Go to "chrome://extensions".
4. Turn on "Developer mode" (switch at the top right).
5. Click "Load unpacked" and choose the "extension/" folder.
6. Open a new tab and you'll see it.

### Note: It does not make any internet requests unless you use the search bar or the browser's geolocation service.

## How the moon and sun data works:

All the math for the moon and sun is done locally in a file called "astro.js".  
It uses standard formulas from astronomy books (like Jean Meeus and SunCalc).  
The times are usually correct within a minute or two which is good enough for a dashboard.
